已接入三种方法节点和三个模板，复用平台的数据版本选择、画布编排、节点试运行、结果保存、资产流转和空间工作台。

原始目录：`D:\data\full_stage_tiller_tifs`，保留不变。

| 阶段 | 采集日期 | 数据版本 ID |

准备或重新注册：

```powershell
.\.venv\Scripts\python.exe scripts\prepare_research_demo.py
```

此脚本需要现有平台数据库及管理员，运行前备份 SQLite；重复执行保留既有数据版本，不覆盖原始影像。Geo 依赖需要 `pip install -e .\backend[geo]`。

## 演示操作

1. 启动 `start-backend.bat`、`start-frontend.bat`，打开 `http://127.0.0.1:5180/workflows`，使用已有演示账号登录。
2. 展示独立成果时先清空画布，再打开“节点库 → 模板”，找到以“科研成果”开头的模板，点击“使用示例输入”，自动接入已注册的真实影像。“插入空模板”用于自行选择输入。
3. 两个分蘖模板默认使用 2025-03-25 数据；修改“数据集版本”节点可选择其他日期。
4. 选择方法节点，点击现有的节点试运行按钮，查看原图、特征图、结果图、光谱曲线和分区统计。
5. 修改植被阈值、融合权重或分析分辨率，重新试运行。预览始终由后端读取真实栅格计算。
6. 校验、保存并运行整条流程；末尾的结果保存节点注册 GeoTIFF，可在资产入口送到空间工作台。
7. 碳交换模板连接四个日期，预览中切换日期，点击结果图查询同一位置的阶段曲线。

碳交换查询采用 32×32 网格近似采样，空白区不返回数值。结果文件保留四个日期波段；地图叠加默认显示第一日期，其他日期在节点报告中切换。

## 方法和输出含义

- `research.structure_tiller`：NDVI 阈值提取植被，计算局部覆盖和 RGB 纹理，按权重融合成 0–1 相对密度指数。
- `research.spectral_transfer`：提取 NDVI、NDRE，构造参考特征并加权融合成 0–1 指数。该简化计算没有运行完整 PROSAIL 或拟合 TCA。
- `research.carbon_potential`：将日期影像重投影到同一网格，以四期共同有效像元计算植被活性和覆盖衍生的 0–1 碳交换潜势指数。

用于展示成果的输入—处理—输出流程。未接入论文训练模型、实测标定、气象驱动或通量观测；不输出株/平方米、真实 NEE 通量或论文验证精度。色标固定为 0–1，避免逐期拉伸造成虚假的变化。

运行生成 GeoTIFF 和 report.json。保存的资产包含方法、日期、单位、范围和阶段统计。数据和数据库未发布到 GitHub Pages；现有线上演示仍使用原示例。
