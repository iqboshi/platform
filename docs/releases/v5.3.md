# v5.3 Release Notes

## Focus

`v5.3` consolidates the platform around reusable cross-page flows instead of isolated feature pages.

## Included Changes

- Workflow starter inputs now follow a shared contract for dataset versions, saved ROIs, model versions, and GEE credentials.
- Workflow preview outputs can advertise structured next actions so qualifying results can flow into the spatial workspace or back into reusable assets.
- A normative workflow node extension standard was added for future agents and contributors.
- The workspace module registry and generated module catalog were synchronized, including corrected Chinese copy.
- Root project documentation was updated to reflect the current platform architecture instead of the original scaffold state.

## Validation

- `npm run lint --workspace @platform/web`
- `npm run test --workspace @platform/web`
- `npm run build --workspace @platform/web`
- `python .\scripts\validate_docs.py`
- `.venv\Scripts\python.exe -m pytest .\backend\tests`

## Follow-Up

- Backend startup still emits FastAPI `on_event` deprecation warnings and should move to lifespan handlers in a later release.
- Frontend production build still reports several large chunks and should be revisited with additional code splitting.
