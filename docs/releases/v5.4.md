# v5.4 Release Notes

## Focus

`v5.4` turns workflow node authoring into a governed workflow instead of a memory-based process.

## Included Changes

- Added `scripts/create_workflow_node_scaffold.py` to generate starter packs for new workflow nodes.
- Added `scripts/validate_workflow_nodes.py` to validate backend catalog contracts and frontend mock parity.
- Wired workflow node validation into GitHub Actions backend CI.
- Updated the workflow node extension standard to include scaffold usage and validation requirements.
- Brought the frontend mock workflow catalog back into sync with the backend node set.

## Validation

- `python .\scripts\validate_workflow_nodes.py`
- `python .\scripts\create_workflow_node_scaffold.py --node-type custom.example_node --label "Example Node" --dry-run`
- `npm run lint --workspace @platform/web`
- `npm run test --workspace @platform/web`
- `npm run build --workspace @platform/web`
- `python .\scripts\validate_docs.py`
- `.venv\Scripts\python.exe -m ruff check backend/src backend/tests`
- `.venv\Scripts\python.exe -m pytest backend/tests`
- `.venv\Scripts\python.exe -m compileall backend/src`

## Follow-Up

- Backend startup still emits FastAPI `on_event` deprecation warnings and should move to lifespan handlers later.
- The workflow node scaffold generator currently outputs snippet packs rather than directly patching the source catalog.
